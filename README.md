## 📖 Overview

**Librar** is a streamlined desktop application engineered to simplify library operations. Built with C# and Windows Forms, it provides an intuitive interface powered by Guna.UI2 for tracking cataloged books, managing member profiles, and executing issue/return transactions smoothly.

---

## ✨ Features

- **📚 Book Management:** Easily add, update, catalog, and remove books from the library database.
- **🔍 Fast Search & Filtering:** Instantly locate titles, authors, categories, or available inventory.
- **🔄 Borrowing & Return System:** Track active loans, due dates, return statuses, and overdue entries.
- **👥 Member Records:** Maintain comprehensive profiles, contact details, and borrowing histories.
- **🎨 Modern UI/UX:** Clean, dark/light compatible Windows Forms interface crafted using Guna.UI2 controls.

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed before starting:
- **Visual Studio 2019 / 2022** with the **.NET desktop development** workload selected.
- **.NET Framework 4.8 SDK**
- **Windows 10 / 11**

### Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/DevHatemAlDouh/librar.git
   cd librar
   ```

2. **Open the Project:**
   Double-click `Librar.sln` to load the project in Visual Studio.

3. **Restore Dependencies:**
   NuGet will automatically restore required packages (including `Guna.UI2`). If needed, right-click the solution in Visual Studio and choose **Restore NuGet Packages**.

4. **Build & Execute:**
   Press `F5` or click **Start** in Visual Studio to run the application.
